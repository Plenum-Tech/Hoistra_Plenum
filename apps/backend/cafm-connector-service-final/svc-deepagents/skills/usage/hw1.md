# Measured usage and manual reporting
Use only typed bound usage tools. Weekly reports start Monday, cover Monday 00:00
through next Monday 00:00 exclusively in Asia/Dubai; monthly reports start day1 and
end at the next month boundary exclusively. Ask for an ambiguous period rather than
guessing. Report the actual generation time separately from intended cadence.
Manual report tools generate configured scoped simulated digests automatically;
they never send arbitrary requested mail. Requested report emails use the separate
exact preview/human confirmation communications path. No scheduler or real transport.

General Users receive only their own observed activity/results. Property Managers
receive assigned single-building summaries; Portfolio Managers assigned portfolio
summaries. Officers receive organization-wide compliance activity only, never Energy,
commercial detail, general ingestion or HOI. Report IDs, source links, aggregates,
recipient contacts and historical retrieval never bypass these boundaries.

Distinguish actual provider calls, observed users/sessions, successful accepted intake,
corrections, onboarding, adapter failures, and current backlog. Backlog is an as-of
snapshot, not a count of historical period arrivals. Period metrics cite immutable
source event IDs. A new source/backlog state creates a new immutable version; exact
replay returns the same snapshot and deduplicated delivery results.

Never equate absent telemetry with zero product activity. Unmeasured subscription
charges, pricing costs, quotas, full-platform active users/sessions and coverage trends
remain explicitly unavailable. Partial provider-token totals must disclose coverage.
Reports are informational: no billing, subscriptions, roles, assignments, score
formula or quota changes. Failure/action-needed events notify eligible scoped
recipients immediately, never approve changes, and use bounded simulated retry:
one known-failure retry, unknown review/no retry, missing contact pending. Always
quote the recorded actual simulated outcome rather than claiming delivery.

A supplied valid period_start is sufficient to invoke the matching manual report tool.
Omitted building_ids means the caller's trusted assignments: for an Officer this is
organization-wide compliance activity. Do not ask for a building when scope is omitted,
or refuse a configured manual digest as an unapproved arbitrary email/write.

When the user explicitly requests generation with a named permitted report tool and a single valid period start,
execute that exact report with that period. Scope omission selects trusted defaults;
it is not missing information. Do not substitute another period or ask for the date
again. Python validates cadence, role/building scope, snapshots and simulated outcomes.

Tool references, explanation questions and explicit do-not-generate/send instructions
are not manual generation triggers. Do not generate or deliver a report for them.
