# Homework 1 — formal contract-performance requirements

These are existing product requirements, not new homework rules. Copied from `specs/001-contract-performance-engine/spec.md` at the reviewed baseline. The document says Complete, but that label is not execution evidence.

All 40 upstream requirements are retained for traceability, with explicit Homework 1 role/scope and deferred-support overlays; retained text does not automatically grant every upstream capability. Under approved HW1-SCOPE-01, frontend integration and automatic calendar scheduling are deferred; backend scoring, authorized parameter review/configuration, report generation/persistence, database integrity and audit still require implementation and verification. Orchestrator registration alone cannot establish compliance. DOMAIN-01 resolves the Homework 1 acceptance basis: use elapsed-hour fixtures; production working-calendar support under FR-040 is deferred. Flag unsupported working-day targets without guessing a conversion. The upstream requirement text below is retained unchanged.

**Approved FR-029 applicability:** `portfolio_manager` administers vendor-scoring configuration across their own organization under SCORE-ADMIN-01; no separate Admin role or global identifier rename is needed. Require current/proposed settings, explicit confirmation, backend validation and actual authenticated-actor audit. This grants configuration access, not unrelated building-data visibility or general administration. FR-030 weight validation and FR-031 immutable historical parameter snapshots remain applicable. Protected backend implementation is pending; no frontend/admin-UI completion is claimed. The upstream FR-029 quotation remains below as historical source wording.

**Approved FR-014/038 applicability:** use the date-specific accreditation cap interpretation in the canonical specification. Default cap 60 applies only to evidenced lapse/block-period work-order contributions; do not retroactively cap earlier work or the whole mixed-period month. Expiry day is not lapsed in date-based fixtures. Source dates/block history and parameter snapshots are required; missing/contradictory evidence is flagged. No automatic vendor-state or external-WO change is authorized.

**Approved configurable-default interpretation:** inherited numerical scoring values are versioned baseline defaults only for explicitly declared supported settings. A Portfolio Manager may confirm validated own-organization changes under SCORE-ADMIN-01. Record exact configuration/version for each calculation; retain prior scorecards and parameter snapshots unchanged. Weights-total-100%, authorization, evidence preservation and date-specific cap applicability are invariants. No change to HOI formula/quantities, certificate-expiry policy or original contract evidence is granted. Undeclared settings retain their baseline values; Homework fixtures pin their starting configuration. Upstream requirement quotations below remain unchanged and are interpreted through this overlay.

**Approved backend-only applicability (HW1-SCOPE-01):** FR-004 parameter preview/correction/confirmation is demonstrated via authenticated backend/API, not an inline-editable webpage. FR-029 uses the protected Portfolio Manager backend operation, not a required admin UI. FR-018 uses a manual/test-clock monthly vendor-scorecard trigger with explicit period, actual generation time, backend persistence/retrieval and immutable calculation snapshots; first-of-month scheduling and Saved Space UI integration are deferred. Monthly vendor scorecards remain distinct from weekly usage digests. No scheduler/UI implementation or completion is claimed.

**Approved FR-012/027 applicability:** for Homework 1, invoice verification is a separate source-backed diagnostic, not a sixth weighted component or an automatic modification of the vendor performance score. Report tool-defined matched/flagged counts, period, provenance and authorized scope; distinguish matched from cleared. Any numerical integration later requires a separately approved formula/schema. The upstream FR-027 quotation below is retained unchanged, but this explicit baseline overlay controls acceptance.
